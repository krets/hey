# hey

Quick LLM access with your current shell context. Debug a failing command,
summarize a file, or just ask.

```sh
hey how do I untar this again
ls -l | hey which of these files looks the most suspicious
cat package.json | hey explain this to me like I'm five
git diff | hey write a commit message, but dramatic
```

## Get started

1. Download the binary for your platform from [Releases](../../releases) and put
   it on your `PATH`.
2. Run `hey config init`.

That's it.

More in the [guide](docs/guide.md).
